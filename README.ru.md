## Инженерное программное обеспечение для реальных изделий

**Tusyndon Industrial Software** разрабатывает специализированные приложения для механического проектирования, подготовки производства, выпуска инженерной документации и работы с BIM-данными. **Tusyndon Designer** — флагманская открытая инженерная платформа: настольная среда с рабочими модулями для параметрического CAD на основе истории построения и проектирования с применением моделирования.

## Инженерные основы

<table>
  <tr>
    <td width="50%" valign="top">
      <h3>Параметрическая модель</h3>
      <p>Ограничения эскиза, именованные размеры, зависимости операций, детерминированное перестроение и сценарии редактирования или переопределения сохраняют проектный замысел.</p>
    </td>
    <td width="50%" valign="top">
      <h3>Геометрия и топология</h3>
      <p>B-Rep-моделирование на базе OCCT предоставляет тела, поверхности, топологию и визуализацию для профессиональных CAD-процессов.</p>
    </td>
  </tr>
  <tr>
    <td width="50%" valign="top">
      <h3>Целостность документа</h3>
      <p>Транзакции документов, идентификация по ObjectId, постоянные ссылки и отмена или повтор команд защищают непрерывность модели.</p>
    </td>
    <td width="50%" valign="top">
      <h3>Профессиональная настольная среда</h3>
      <p>Ленточные команды, закрепляемые панели, MDI-виды, выбор, взаимодействие и модульные рабочие среды поддерживают долговременное развитие продукта.</p>
    </td>
  </tr>
</table>
