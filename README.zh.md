## 面向真实产品研发流程的工业软件

**图随形动工业软件**面向机械设计、制造准备、工程交付与 BIM 数据流程研发专业应用。**Tusyndon Designer** 是旗舰开放工程平台，为历史树参数化 CAD 与仿真驱动设计提供桌面端、工作台式的软件基础。
