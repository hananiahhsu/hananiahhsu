## SolidDesigner——参数化工程基础

SolidDesigner 是基于可复用 **Alice** 基础平台与 **OpenCascade** 几何内核构建的 C++17/20 桌面应用。项目当前处于**活跃开发的预览阶段**：现有代码正在建立可靠的工程基础，高级 CAD、CAE、优化设计与智能辅助能力按照公开路线持续完善。

<table>
  <tr>
    <td width="33%" valign="top">
      <h3>参数化设计意图</h3>
      <p>
        草图约束、命名尺寸、特征历史、依赖驱动的重新生成以及编辑与重定义流程，
        共同形成可以被系统理解和维护的工程变更模型。
      </p>
    </td>
    <td width="33%" valign="top">
      <h3>工程几何模型</h3>
      <p>
        以 OCCT 边界表示建模、持久对象标识、文档事务与多种几何表示为基础，
        在设计持续演进过程中维护模型关系的连续性。
      </p>
    </td>
    <td width="33%" valign="top">
      <h3>专业工作台</h3>
      <p>
        功能区驱动的桌面外壳、可停靠面板、多文档视口、命令体系与模块化工作台，
        支撑零件、装配、草图、工程图、仿真和 BIM 等产品方向。
      </p>
    </td>
  </tr>
</table>

> **产品阶段：** 活跃开发 · 预览阶段。当前实现范围与公开路线以 [SolidDesigner 仓库](https://github.com/Ludwigstrasse/SolidDesigner)为准。
