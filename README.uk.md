## Інженерне програмне забезпечення для реальних виробів

**Tusyndon Industrial Software** розробляє спеціалізовані застосунки для механічного проєктування, підготовки виробництва, випуску інженерної документації та роботи з BIM-даними. **SolidDesigner** — провідна відкрита інженерна платформа: настільне середовище з робочими модулями для параметричного CAD на основі історії побудови та проєктування із застосуванням моделювання.

## Інженерні основи

<table>
  <tr>
    <td width="50%" valign="top"><h3>Параметрична модель</h3><p>Обмеження ескізу, іменовані розміри, залежності операцій, детерміноване перебудування та сценарії редагування або перевизначення зберігають проєктний задум.</p></td>
    <td width="50%" valign="top"><h3>Геометрія і топологія</h3><p>B-Rep-моделювання на базі OCCT надає тіла, поверхні, топологію та візуалізацію для професійних CAD-процесів.</p></td>
  </tr>
  <tr>
    <td width="50%" valign="top"><h3>Цілісність документа</h3><p>Транзакції документів, ідентифікація за ObjectId, сталі посилання та скасування або повтор команд захищають неперервність моделі.</p></td>
    <td width="50%" valign="top"><h3>Професійне настільне середовище</h3><p>Стрічкові команди, закріплювані панелі, MDI-подання, вибір, взаємодія та модульні робочі середовища підтримують довготривалий розвиток продукту.</p></td>
  </tr>
</table>
